# Suki Mod (NeoForge 1.21.10)

## Build
1. Install JDK 21.
2. Di folder ini: `./gradlew build`  (Windows: `gradlew.bat build`)
3. Hasil jar: `build/libs/sukimod-1.0.0.jar` -> taruh di folder `mods` NeoForge 21.10.x.

## Test cepat di dev
`./gradlew runClient` lalu di world creative: `/summon sukimod:suki` atau ambil Suki Spawn Egg.

## Cara main
- Suki liar: kasih **Cookie** (peluang 1/3 per cookie) buat jinakin.
- Jinak: dia ngikutin & ngebelain lo kayak wolf.
- Klik kanan pegang **Emerald** -> dapet **1 Diamond**.
- **Shift + klik kanan** -> duduk/berdiri. Klik kanan pegang Cookie -> heal.
